How the Action attribute works

... in my own words

The action attribute on a form tag tells the browser where to send the form data when the user clicks submit. Its value is a URL, usually a page or script on a server that is set up to receive and process what the user typed.

For example, in <form action="https://api.formbucket.com/f/c2K3QTQ" method="post">, the form data goes to FormBucket, which saves the message and can email it to the site owner. The method attribute works with action and says how the data is sent, either get or post.

If a form has no action attribute, the data is sent back to the same page the form is on, so without a proper action the information the user enters never reaches anywhere useful.
