How the Action attribute works

... in my own words

The action attribute tells a form where to send the information the user typed in once they hit submit. Its value is a URL, usually a page or script on a server that is set up to take in the data and do something with it. For example, a contact form can have its action point to FormBucket, so when someone sends a message, FormBucket saves it and can email it to the site owner. Action works together with the method attribute, which says whether the data gets sent using get or post. If you leave the action out, the form just sends the data back to the same page it's on.
